### 🚀 Highlights & Features:

- **Dark & Light Mode Engine**: Smooth theme toggle with persistent state saved in `localStorage`.
- **Integrated ATS-Ready Resume**: Includes a dedicated printable resume (`assets/resume.html`) with print-to-PDF styles and clean ATS formatting.
- **Responsive Interactive Showcase**: Detailed project & certificate preview modals, copy-to-clipboard helpers, and working contact form with prefilled email dispatch.

## 🌐 Free 1-Click Deployment

### 1. Deploying to GitHub Pages (Recommended)
1. Initialize Git in the project directory:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of Jatin developer portfolio"
   ```
2. Create a new GitHub repository named `portfolio` (or `jatin713.github.io`).
3. Push your repository:
   ```bash
   git branch -M main
   git remote add origin https://github.com/jatin713/portfolio.git
   git push -u origin main
   ```
4. Go to **Repository Settings** > **Pages** > Set source to `main` branch / root directory. Your portfolio will be live at `https://jatin713.github.io/portfolio`!

### 2. Deploying to Vercel or Netlify
- Drag and drop the `jatin-portfolio` folder directly into [Netlify Drop](https://app.netlify.com/drop) or import from GitHub on [Vercel](https://vercel.com).
- It will go live in under 30 seconds with automatic HTTPS and CDN acceleration!
